帮助与使用说明

HobIT 是一个综合性的生物信息学工具包，用于同源异型盒 (Homeodomain) 基因的鉴定、注释和结构预测。

主要功能

  • 基于 BLAST 的同源搜索：使用 tblastn 在基因组中搜索同源异型基因。
  • HMMER 结构域精修：使用 Pfam 模型 (PF00046) 精确界定结构域边界。
  • 基因结构预测：可选使用 Exonerate 预测完整的基因模型（内含子/外显子）。
  • 注释比对：可与参考 GFF 文件比对，区分“已知”与“新颖”基因。
  • ESM2 AI 语义打分 (新功能)：调用 Meta 的蛋白质语言模型，对预测出的基因进行相似度评分，辅助过滤假阳性。
  • 蛋白质模式：使用 HMM 模型直接扫描蛋白质序列。

用户指南

模式 1：基因组模式 (DNA)

当你拥有基因组组装文件 (.fasta) 并想从中寻找基因时使用。

  • 基因组序列：拖拽上传你的基因组 FASTA 文件。
  • 参考序列 (可选)：拖拽包含已知 Homeodomain 的蛋白文件。如果不传，程序将使用内置数据库。
  • 参考注释 GFF (可选)：拖拽 .gff3 文件。程序会将预测结果与已知基因进行位置比对。
  • Exonerate：勾选此项以预测完整基因结构（由于计算复杂，速度会变慢）。
  • ESM2 AI Scoring：勾选此项将在主程序运行完毕后，利用 AI 对候选序列进行评分。首次运行该功能需联网下载约 30MB 的模型。

模式 2：蛋白质模式 (AA)

当你拥有一组蛋白质序列 (.fasta) 并想筛选其中的 Homeodomain 时使用。

  • 蛋白质序列：拖拽上传你的蛋白质 FASTA 文件。
  • HMM 模型 (可选)：拖拽自定义的 .hmm 文件。如果不传，默认使用 Pfam PF00046。

输出文件说明

对于名为 "genome.fasta" 的任务，结果将保存在 results/任务ID/ 文件夹中：

文件名描述
isengard_output.xlsx 主结果表格。包含评分、位置、预测的家族/类别 (Family/Class) 和序列。
AI_Scoring_Report.xlsx (仅在勾选 ESM2 时生成) AI 基于语义相似度对候选序列的打分排名。
hobit_protein.fasta 提取出的同源异型结构域氨基酸序列。
hobit_genes.gff3 基因结构注释文件（仅限基因组模式）。可导入 IGV 或 JBrowse 查看。
hobit_cds.fasta 预测基因的编码序列 (CDS)。

Excel 列名解释

  • Scaffold/Location: 基因在基因组上的位置。
  • Family/Class: 预测的基因分类（例如 Hox1, ANTP）。
  • E-value: 统计显著性（数值越小越好，例如 1e-50）。
  • Notes: 重要标记（如 CHIMERIC_HIT 嵌合体警告, REF_MATCH 已知基因匹配, NOVEL_PREDICTION 新发现基因）。

常见问题 (Troubleshooting)

报错 "Command not found"?
请确保你安装了必要的生物信息学工具 (BLAST+, HMMER, Exonerate)。

  • Mac: 终端运行 brew install ncbi-blast hmmer exonerate
  • Ubuntu: 终端运行 sudo apt-get install ncbi-blast+ hmmer exonerate

浏览器没有自动打开？
请在浏览器地址栏手动输入 http://127.0.0.1:5000 (或终端提示的端口号)

Help & Manual

A comprehensive bioinformatics toolkit for Homeobox (Homeodomain) identification, annotation, and gene structure prediction.

Features

  • BLAST-based Homology Search: Uses tblastn to find homeobox genes in genomic sequences.
  • HMMER Domain Refinement: Uses Pfam profiles (PF00046) to precisely define domain boundaries.
  • Gene Structure Prediction: Optionally uses Exonerate to predict Introns/Exons.
  • Annotation Comparison: Compare predictions against a reference GFF to identify "Novel" vs "Known" genes.
  • ESM2 AI Semantic Scoring (New): Uses Meta's protein language model to score predictions based on semantic similarity, helping filter false positives.
  • Protein Mode: Directly scans protein sequences using HMM models.

User Guide

Mode 1: Genome Mode (DNA)

Use this when you have a genome assembly (.fasta) and want to find homeobox genes.

  • Genome Sequence: Drag & drop your genome FASTA.
  • Reference Query: (Optional) A protein FASTA containing known Homeodomains.
  • Reference Annotation: (Optional) A .gff3 file. HobIT will check if its predictions overlap with known genes.
  • Exonerate: Check this to predict full gene models (Exons/Introns).
  • ESM2 AI Scoring: Check this to run an AI-based validation after the main analysis. Requires internet connection on the first run to download a small 30MB model.

Mode 2: Protein Mode (AA)

Use this when you have a proteome (.fasta) and want to screen for Homeodomain motifs.

  • Protein Sequence: Drag & drop your protein FASTA.
  • HMM Model: (Optional) Custom .hmm file. Defaults to Pfam PF00046.

Output Files

Results are saved in the results/ folder:

File NameDescription
isengard_output.xlsx Main Result Table. Contains scores, locations, predicted Family/Class, and sequences.
AI_Scoring_Report.xlsx (If ESM2 enabled) Independent ranking of candidate sequences scored by the AI model.
hobit_protein.fasta Extracted amino acid sequences of the identified Homeodomains.
hobit_genes.gff3 Gene structure annotations (Genome Mode only). Compatible with IGV/JBrowse.
hobit_cds.fasta Coding sequences (CDS) of predicted genes.

Excel Column Key

  • Scaffold/Location: Genomic position.
  • Family/Class: Predicted classification (e.g., Hox1, ANTP).
  • E-value: Statistical significance (lower is better).
  • Notes: Important flags (e.g., CHIMERIC_HIT, REF_MATCH, NOVEL_PREDICTION).

Troubleshooting

"Command not found" error?
Ensure you have installed the required tools (BLAST+, HMMER, Exonerate).

  • Mac: brew install ncbi-blast hmmer exonerate
  • Ubuntu: sudo apt-get install ncbi-blast+ hmmer exonerate

Browser doesn't open?
Manually enter http://127.0.0.1:5000 (or the port shown in terminal) in your browser address bar.
